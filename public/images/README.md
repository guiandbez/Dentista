# Imagens utilizadas no site

As imagens do site são mantidas localmente em suas pastas por tipo de conteúdo.

- `dra-bruna/bruna-transparente-2160.webp`: retrato recortado usado no hero.
- `dra-bruna/sobre-mim-TROCAR.webp`: imagem provisória da recepção na seção “Sobre mim”; substituir pela foto da Dra. Bruna.
- `tratamentos/facetas-lentes.webp`: foto de sorriso para Facetas / Lentes.
- `tratamentos/harmonizacao-facial.webp`: foto de paciente para Harmonização facial.
- `tratamentos/clareamento-dental.webp`: foto de sorriso para Clareamento dental.
- `clinica/espera-896.webp`: sala de espera.
- `clinica/corredor-1170.webp`: corredor.
- `clinica/recepcao-896.webp`: recepção.
- `clinica/placa-896.webp`: placa do consultório.
- `tratamentos/implantes.webp`: imagem provisoria de implante dentario; foto de Ozkan Guner no Unsplash (https://unsplash.com/pt-br/fotografias/boca-de-uma-pessoa-com-dentes-e-lingua-PJAVJuT4HOg).
